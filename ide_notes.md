# Git в VS Code: что удобно, что неудобно

## Удобно в VS Code
1. **Diff в один клик** — цветом показано, что изменилось в каждой строке.
2. **История коммитов в виде графа** — наглядно видно ветвление.
3. **GitLens** — показывает автора и дату для каждой строки (визуальный git blame).

## Удобнее в терминале
1. **Interactive rebase** (`git rebase -i`) — объединять коммиты, переупорядочивать, менять сообщения. В UI это неудобно и работает нестабильно.
